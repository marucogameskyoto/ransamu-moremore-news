# 日本らんさむもれもれ速報

国内組織が公式に公表した、ランサムウェアまたは不正アクセスに伴う情報漏えい・漏えいのおそれをまとめる静的サイトです。

## 自動更新

GitHub Actions が毎日 07:00、12:00、18:00、23:00（日本時間）に実行します。

- JPCERT/CC の公式RSSを確認します。
- `sources.json` に登録した公式ニュース一覧を巡回します。
- 一覧ページで候補を拾い、登録した公式ホスト内の記事本文を確認します。
- URLホストを許可リストで制限し、robots.txtの巡回禁止を尊重します。
- 記事本文に不正アクセス等と漏えいの両方が確認できないページは掲載しません。
- 公開する要約は見出し・日付・公式リンクを基本とし、漏えい件数は原文で確認できた値のみ表示します。

## 収集元と制約

巡回先は `sources.json` の `crawl_sources` に個別登録します。現在の巡回対象は京王電鉄、日本酒類販売、ワシントンホテル、日本資産総研、RIZAP、長野都市ガスです。公開サイト全体を網羅するクローラーではなく、登録した一覧ページから確認できる発表だけが対象です。JavaScriptで後から描画される一覧、PDFだけの発表、未登録の組織は取得できない場合があります。新しい公式ソースを追加する際は、組織の公式サイトであることと一覧ページの構造を確認して登録してください。

## 公開

GitHub Pages は GitHub Actions から `site/` をデプロイします。
