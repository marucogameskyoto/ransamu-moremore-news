# らんさむもれもれ速報 — GitHub Actions自動更新

公式機関の公開RSSだけを1日4回取得し、発表元・発表日・公式原文リンクを掲載するサイトです。記事欄は発表の見出しと確認できるメタデータに限定し、感想・推測・報道記事・攻撃者の主張・リークサイト・流出ファイルは掲載しません。

## 記事の定型項目

- 発表元（公式フィード名）
- 発表タイトルと原文リンク
- 発表日
- 対象組織（公式本文で明確に確認できる場合のみ。RSSの見出し・メタデータから安全に確認できない場合は「記載なし」）
- 発表された件数（本文に明記がある場合のみ。現行の軽量版では自動抽出せず「記事に明記なし」）

現在の設定はCISAとJPCERT/CCの公式フィードです。JPCERT/CCは公式説明でRSSの配信内容を注意喚起・緊急報告等として案内しています。CISAの注意喚起は企業被害の網羅一覧ではありません。従ってこのサンプルは「公式フィードの自動ダイジェスト」であり、日々の全漏洩件数を示すものではありません。

## GitHubへ載せる

1. このフォルダの中身を新しいGitHubリポジトリのルートへアップロードします。
2. **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. **Actions** タブで `Update digest and publish` を手動実行します。成功後、Pagesの公開URLが表示されます。
4. 以後は毎日07:00、12:00、18:00、23:00（日本時間）にRSS取得・更新・公開します。

## 公式収集元を追加する

`sources.json` に公式機関のHTTPS RSSを追加し、`allowed_host` にその機関の正確なホスト名を設定してください。スクリプトはホスト名が一致しないURLを拒否します。RSSの利用条件を確認し、取得頻度を守ってください。

組織名や件数を自動推測していません。誤った被害情報を公開しないため、原文に明記された値だけを載せる設計です。Amazonアソシエイトの規約に基づく表示文をトップページと広告枠に掲載しています。

## Amazonアソシエイト広告

サイト内の広告枠はAmazonの商品検索リンク用です。AmazonアソシエイトのトラッキングID `pfb-22` をサイト内リンクに設定済みです。ログイン情報やAPIキーはサイトに保存しません。

Amazonアソシエイトの参加表記・プライバシー説明など、アカウント管理画面で案内される要件を公開サイトに反映してから運用してください。Amazon商品検索リンクにはトラッキングIDを設定済みです。

掲載する公式フィード：[CISA Advisories](https://www.cisa.gov/cybersecurity-advisories)、[JPCERT/CC RSS](https://www.jpcert.or.jp/rss/index.html)。JPCERT/CC RSSは注意喚起・緊急報告等の更新であり、企業の漏洩発生を網羅するデータではありません。
